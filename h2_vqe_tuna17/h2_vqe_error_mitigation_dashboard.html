⚠️ PEA — Noiseless Only

PEA uses Statevector.from_instruction() which is noiseless — it returns the ideal textbook answer regardless of the noise model. It is not error mitigation under noise, so it is excluded from Tuna-17 results. It only runs on --noise none.

🔧 CDR Correction Formula

CDR fits measured = a × ideal + b. To correct a raw measurement:

ideal = (raw − b) / a

The old code used a × raw + b (backwards). Fixed to (raw − b) / a.

Can overshoot ground state on some runs — linear model limitation with depolarizing noise.

🔬 Technique Deep Dives

1. Readout Mitigation (TREX)

What: Confusion matrix inversion across all measurement bases.

Math: p_true = M⁻¹ · p_measured

Why: Corrects 2% readout bit-flip error on Tuna-17 without changing the circuit.

2. Symmetry Verification (Odd Parity)

What: Post-selects on odd parity (|01⟩/|10⟩) for Z-basis measurements only.

Why valid: X-X-CNOT gives |10⟩ (odd) at θ=0. State is ~80% odd parity. Post-selection projects onto physical sector.

Why not even: Even-parity post-selection would discard 80% of valid amplitude.

XX group: Not post-selected — X-basis bitstrings don't have computational-basis parity.

3. Adaptive Conservation (Odd Parity)

What: Soft parity reweighting via confusion matrix.

Fix: Physical states changed from even (% 2 == 0) to odd (% 2 == 1) to match the ansatz.

Benefit: 100% shot retention — no post-selection loss.

4. ZNE (Richardson Extrapolation)

What: Gate folding with CX-CX pairs, Richardson extrapolate to 0 CNOTs.

Fix: Quadratic Richardson fit against CNOT counts [1,3,5]. λ=2 → 3 CNOTs, λ=3 → 5 CNOTs.

Compliance: CX-CX pairs are intermediate mitigation gates (allowed).

5. CDR: (raw − b) / a

What: Linear regression: measured = a × ideal + b.

Fix: Correction is ideal = (raw − b) / a, not a × raw + b.

Limitation: Can overshoot ground state — linear model is simple for depolarizing noise.

6. Mitigate During Optimization

What: Readout + symmetry mitigation applied inside the COBYLA cost function.

Result: Optimizer sees mitigated energy each iteration → converges to better parameters.

Final eval: −1.13058 ± 0.00389 Ha over 5 runs.

7. PEC — Post-Selection Invalid

What: Ancilla + syndrome measurement via CNOTs.

Why invalid: Ancilla syndrome post-selection would discard ~96% of shots on H2 X-X ansatz.

Result: Returns raw energy with diagnostic.

8. Randomized Compiling

What: Pauli twirling with sign tracking (P·O·P = s·O).

Result: No gain on depolarizing noise (already stochastic).

9. PEA — Noiseless Only

What: Statevector.from_instruction() at λ=1,2,3, extrapolate to λ=0.

Why excluded: Noiseless — returns ideal answer regardless of noise model. Not mitigation under noise.

Runs only on: --noise none

10. Transpilation O0–O3

What: Qiskit transpiler optimization levels 0–3.

Note: Zero-cost improvement, not a mitigation technique per se.
